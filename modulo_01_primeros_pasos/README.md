# Módulo 1 — Primeros Pasos con Python

En este primer módulo aprenderás los pilares fundamentales de la programación en Python aplicados a la manipulación básica de información y finanzas.

---

## 📚 Lecciones y Archivos de Código

| Archivo | Tema Principal | Conceptos Clave |
| :--- | :--- | :--- |
| [`01_hola_mundo.py`](./01_hola_mundo.py) | Estructura básica de un script | `print()`, comentarios `#` y `"""`, ejecución |
| [`02_variables_y_tipos.py`](./02_variables_y_tipos.py) | Variables y Tipos de Datos | `int`, `float`, `str`, `bool`, `None`, `type()` |
| [`03_entrada_y_salida.py`](./03_entrada_y_salida.py) | Entrada/Salida de Datos | `input()`, `print()`, caracteres de escape `\n` |
| [`04_operadores_y_math.py`](./04_operadores_y_math.py) | Operaciones y Librería `math` | `+`, `-`, `*`, `/`, `**`, `%`, `math.sqrt`, `math.ceil` |
| [`05_manipulacion_strings.py`](./05_manipulacion_strings.py) | Métodos de Cadenas | `.upper()`, `.lower()`, `.strip()`, `.replace()`, `.split()`, `len()` |
| [`06_fstrings_y_formato.py`](./06_fstrings_y_formato.py) | Formateo Avanzado | f-strings `f"..."`, formato decimal `:.2f` |
| [`07_demo_analisis_ventas.py`](./07_demo_analisis_ventas.py) | **Demo de Análisis Básico** | Total, promedio, max, min y cantidad de ventas |
| [`08_reto_resumen_fstrings.py`](./08_reto_resumen_fstrings.py) | **Reto Integrador** | Generador automático de resumen empresarial con f-strings |

---

## 💡 Recomendaciones para los estudiantes
1. Ejecuta cada archivo en tu terminal o VS Code.
2. Lee detenidamente los comentarios explícitos en cada línea de código.
3. Experimenta cambiando los valores de las ventas o datos empresariales.

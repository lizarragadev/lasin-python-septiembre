# Módulo 2 — Lógica y Control de Flujo

En este segundo módulo aprenderás a tomar decisiones condicionales en código, repetir tareas con bucles y aplicar patrones fundamentales de lógica para analizar transacciones y controlar el flujo de ejecución.

---

## 📚 Lecciones y Archivos de Código

| Archivo | Tema Principal | Conceptos Clave |
| :--- | :--- | :--- |
| [`01_operadores_y_condicionales.py`](./01_operadores_y_condicionales.py) | Condicionales Básicos | `==`, `!=`, `>`, `<`, `and`, `or`, `not`, `if`, `elif`, `else` |
| [`02_condicionales_avanzados_y_match.py`](./02_condicionales_avanzados_y_match.py) | Estructuras de Control Avanzadas | Condicionales anidados, Operador ternario, `match-case` |
| [`03_bucles_for_y_range.py`](./03_bucles_for_y_range.py) | Bucles Determinados | Bucle `for`, `range(inicio, fin, paso)`, iteración de datos |
| [`04_bucles_while_y_patrones.py`](./04_bucles_while_y_patrones.py) | Bucles Indeterminados y Patrones | Bucle `while`, `break`, `continue`, contadores, acumuladores, validaciones |

---

## 💡 Recomendaciones
Ejecuta los archivos en orden. Pon especial atención a cómo los bucles `for` y `while` se combinan con `if` para filtrar datos desglosados línea por línea.

# 📦 Ejercicio Práctico Integrador — LASIN Python

Este directorio contiene el **Ejercicio Práctico Integrador** que reúne las competencias fundamentales desarrolladas durante el curso:

* 📄 [**ENUNCIADO.md**](./ENUNCIADO.md): Descripción completa de los requerimientos técnicos, arquitectura, salidas esperadas y criterios de evaluación.
* 📊 [**datos_envios.csv**](./datos_envios.csv): Dataset de prueba con datos limpios, atípicos, duplicados y con errores para probar la resiliencia de tu solución.

### 🚀 Instrucciones para el Estudiante:
1. Lee detenidamente el archivo [ENUNCIADO.md](./ENUNCIADO.md).
2. Crea tu archivo de solución (por ejemplo `mi_solucion_integrador.py`) en este directorio.
3. Ejecuta y valida cada una de las opciones del menú interactivo contra el archivo [datos_envios.csv](./datos_envios.csv).
